# Moira Experiments

Some experiments to benchmark Moira. To run all the experiments,
execute the following command:

``` bash
make
```

Executing all the experiments will take some time. The Makefile also
allows to execute the experiments on a single subject. For example, to
execute only the experiments for the `jhipster-registry` target
execute the following command:

``` bash
make run-jhipster-registry
```
